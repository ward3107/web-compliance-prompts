For people who work with coding assistants

Give your assistant
the right toolkit.

MCP lets a coding assistant read our templates and prepare banner files. Set up the connection once, then ask your assistant to help.

Runs locally in a tool that supports MCP over stdio. Requires Node.js 22 or later on your computer or assistant environment. No npm install, extra account or API key from us is needed. Your AI service has its own terms.

No coding assistant? Use the browser setup instead →
Step 1

Download and extract the folder

Keep the folder in a permanent location on the computer running your assistant. Extract all files. The server file is: mcp/server.mjs.

Download the MCP package

Includes the server, templates and banner files. Nothing installs automatically.

Step 2

Prepare your connection settings

Choose your tool and paste the full path to the file you extracted. The settings are created in your browser.

Copy the path from your file manager. On Windows it might look like: C:\Tools\web-compliance-mcp\mcp\server.mjs. For a remote assistant, use the path in its environment.

Already have a configuration file? Add only the web-compliance entry. Preserve your other connections. Review the configuration before allowing the server to run in your tool.


Step 3
Open your assistant and get started
Reopen the project or start the connection in MCP settings. Confirm web-compliance is connected and exposes four tools, then ask:
Use web-compliance. First show me what I can create. Ask about my website, banner language and privacy policy. Then prepare a banner and show the proposed changes before modifying website files. Do not invent missing details.


What can the assistant do?
  • Explore all 13 templates and 12 themes.
  • Read templates and sources by jurisdiction.
  • Prepare banner files for WordPress or a custom website.
  • Explain integration and testing steps.
You decide what changesOur server returns content only. It does not write files, run commands, call the network or install anything on your site. Your coding assistant may have additional permissions and may send requested content to its AI provider.
Connection not starting?
  • Check that Node.js 22 or later is installed and available to your tool. If needed, install it from its official source and reopen your tool.
  • Check that the path points to server.mjs and the entire folder was extracted.
  • Approve the connection in your tool and check its MCP log.
  • Other tools may use a different configuration format. Use the command and args values according to that tool’s documentation.
