2. Real tracking behavior

Identify the purpose of each script first. In clean browser contexts, inspect network requests, cookies and local/session storage. Agree expected behavior for each actual tool and market before testing. A visual button click or dataLayer event alone does not establish blocking.

Reopen and withdrawUse the persistent preferences control, change the choice and reload. Verify the integration's actual withdrawal behavior; document any required reload or vendor cleanup.not tested
Persistence / blocked storage / GPCTest returning visits, blocked browser storage and Global Privacy Control where supported. Verify the expected signal and UI without relying on a simulated screenshot.not tested
