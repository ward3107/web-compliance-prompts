Three routes, one package
  1. Use the banner: open the studio, select a design, answer the project questions and export a WordPress or universal installation package.
  2. Use the skill: choose the Claude Code, Cursor or Copilot ZIP on the installation page, extract it into your project root and confirm the skill is discovered. The unwrapped generic copy is also in skill/web-compliance/.
  3. Verify the destination: use the acceptance worksheet to record actual results before handing a site to a client.

Scope before installation

The banner communicates consent and does not automatically block scripts from other plugins. Connect and test the site's real trackers. The document generator produces Hebrew drafts for Israel only. All jurisdiction packs still need legal review. This package does not provide an automatic scan, compliance certificate or accessibility certification. The separate reporting skill is not included.

Updates and help

Downloaded and installed copies do not update themselves. Save your project JSON, back up the installed files, review changes and test updates on a staging site. For WordPress, deactivate and remove the previous plugin before uploading a replacement if the dashboard cannot replace it. Removing this component does not remove trackers installed elsewhere.
